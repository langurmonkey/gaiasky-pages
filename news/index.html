Gaia Sky 3.9.0

By tsagrista on 21 Oct 2026

It is time for another Gaia Sky release. Gaia Sky 3.9.0 brings volumetric rendering of the Milky Way, a new SMAA anti-aliasing implementation, a reworked camera, and support for gaiasky:// URLs, among many more new features and bug fixes.

Here is a summary of what’s new in this release:

  • Volumetric rendering of the Milky Way, with dust that actually occludes the stars and other elements behind it.
  • New SMAA anti-aliasing, now the default method.
  • Reworked camera, especially close to planets and other bodies, and smoother gamepad input.
  • gaiasky:// URL protocol support on Windows, Linux, and macOS.
  • The REST server now ships in the main application, with its own preferences section.
  • Sesame name discovery.
  • Light glow halos sized and graded from the physical properties of the light.

If you want to know more, keep reading.

Important

Gaia Sky 3.9.0 requires an update in the base data pack, which replaces the particle-based Milky Way with a volumetric one. You will be notified on startup that an update is available. Please, update!

Windows Defender false positive for LWJGL 3.3.4 in Gaia Sky 3.8.0

By tsagrista on 5 Oct 2026

We have received reports that Windows Defender may detect the file lwjgl-3.3.4-natives-windows-x86.jar included with Gaia Sky as a threat.

We investigated the issue and found strong evidence that this is a false positive affecting the upstream LWJGL 3.3.4 library. The LWJGL project has an issue documenting antivirus detections of its 3.3.4 release, including a Trojan:Win32/Vigorf.A detection by Windows Security:

https://github.com/LWJGL/lwjgl3/issues/1005

Similar reports were also made by users of Necesse, another application using LWJGL. In that case, antivirus software specifically detected the same lwjgl-3.3.4-natives-windows-x86.jar file. The developers subsequently removed the file because it is only needed for 32-bit Windows:

Gaia Sky 3.8.0

By tsagrista on 23 Jul 2026

We are proud to announce the release of Gaia Sky 3.8.0. This release brings a mainor overhaul of the procedural planet generation system, with domain warping, 3D biome LUTs, new presets, and a consolidated single-pass generation pipeline. It also introduces higher resolution icons for HiDPI, custom view mode panes, and many bug fixes.
