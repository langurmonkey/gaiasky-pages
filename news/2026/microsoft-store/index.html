Microsoft Store package

We have published Gaia Sky to the Microsoft Store for one-click install for users of Windows.

By tsagrista on 19 Oct 2026

Gaia Sky is now available on the Microsoft Store! Windows users can install it directly from the store, making it easier than ever to get started exploring the universe.

Publishing the app turned out to be surprisingly quick and painless. Kudos to Microsoft for making the process so straightforward for developers!

Microsoft Store listing
Install Gaia Sky (only works on Windows)
For Windows 10/11 (x86_64)

Running Windows 10 or 11 on an x86-64 PC? Click the button above to open Gaia Sky in the Microsoft Store and install it in just a few clicks.
